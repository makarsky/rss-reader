# rss-reader
Simple RSS reader

## Requirements:
Docker.

## Installation:
1. Clone the project
2. Run `make install`
3. Open http://127.0.0.1:84

The Node container installs dependencies and serves the Vite dev server on port 5174. Nginx stays on port 84. Run `make help` to list the other commands.

## Running tests:
```
make test
```
